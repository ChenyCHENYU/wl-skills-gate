# 09 自测与真实环境演练

对应 A6/E2、第十六章。固定命令：

```bash
npm test
# 仅 fixture：
node bin/wl-skills-gate.js self-test
```

0.6.1 的 npm test 包含 129 项单元测试、29 个 fixture 场景和 17 个本地 Git/签名/制品集成场景；self-test 不包含全部单元/集成。fixture 在临时目录执行，不污染源码和发布包。

新增反向验证覆盖：关键失败基线/豁免、严重程度合并、历史扩张、增量误关闭、自批例外、JUnit 截断/零用例/跳过/计数/必测、旧报告、非零退出空报告、假 SHA、脏代码/扫描漂移、部分暂存、实际版本、修复代码漂移/任意命令/失败回滚/复扫期间源码变化、伪造签名/作业/时间/环境/档位、替换制品、Review 缺失/伪造/自审、竞争候选、项目 Hook 不进入特权控制器、控制器审计前置和异常清理。

集成使用临时本地 bare remote 和临时测试密钥；未接触真实分支、registry、部署或群通知。通过证明包在这些夹具中行为正确，不能替代以下实测：

| 平台验收 | 必需证据 |
|---|---|
| 普通账号写共享分支被拒 | 保护规则、真实普通/受控账号拒绝/放行 |
| 删除/覆盖 CI include 后不能晋级 | 平台强制或独立受控晋级拒绝；巡检差异事件 |
| 签发来源权威查询与凭据隔离 | 实际 API 查询、受控 job/template/Runner、密钥授权 |
| 前后端真实检查、业务与 Review | 实际工具版本、覆盖分母、原场景和复验 |
| 双仓发布组合、环境和恢复 | release-manifest、真实制品/配置/脚本、冒烟和恢复记录 |
| 台账与群闭环 | 重复失败幂等、消息跳转/认领、逾期升级、复验关闭及通知失败兜底 |

按“仅报告/已阻断/已闭环”逐项目登记，未接入项明确保留，不能将无数据标成正常。
